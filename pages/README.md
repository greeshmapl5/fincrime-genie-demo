# Pages content (Discover, Beta)

All content is fictional and synthetic. Not regulatory guidance. Pages data is stored in plain text and may be replicated globally, so never put real client policy, PII or regulated data in a page.

Each file in this folder is the source text for one page. Fields map to the page form in **Discover**:

| Field in the file | Where it goes |
|---|---|
| Title | Page name |
| Domain | `Financial Crime` (create it first, a page cannot be published without a domain) |
| Synonyms | Synonyms chips |
| Description | Description box |
| Definition | Definition section of the body |
| Business use | Business use section of the body |
| Related assets and sources | Related assets and Sources lists |
