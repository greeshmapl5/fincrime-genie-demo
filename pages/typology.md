# Typology

- **Domain:** Financial Crime
- **Synonyms:** alert category, alert type, pattern category
- **Description:** The category of pattern an alert was raised for.
- **Related assets and sources:** `fincrime.gold.alerts`

## Definition

A typology is the category of pattern that a monitoring alert was raised for. Each alert has one typology, in the column alerts.typology.

## Business use

The typologies in the data
- **Structuring**: defined, see the Structuring page.
- **Rapid pass-through**: defined, see the Rapid pass-through page.
- **Mule account**: a label only. There is no definition of it in this workspace.
- **Unusual volume**: a label only. There is no definition of it in this workspace.

For a label with no definition, say that it has no definition here. Do not describe what it means or add a description.

How to describe it (approved wording)
- Say "the alert category" or "the typology the alert was raised for".
- Say "a pattern consistent with <typology>".
- Do not call any typology a "suspicious activity pattern".
- Do not add anything that is not on this Page.

How to read it
- A typology says what the monitoring looked for. It does not say what a customer did or why.
- The investigator decides the outcome of each alert.
